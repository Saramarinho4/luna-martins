# Luna Martins ✦

Site-conceito de portfólio para uma UGC Creator fictícia.

O projeto foi desenvolvido para demonstrar uma experiência digital profissional voltada para creators, com foco em conteúdo UGC, beauty, lifestyle, fashion e produção de conteúdo para marcas.

## ✦ Sobre o projeto

O site apresenta:

- apresentação da creator
- serviços de UGC
- portfólio de projetos demonstrativos
- processo de trabalho
- depoimentos ilustrativos
- formulário de contato
- design responsivo para desktop, tablet e mobile

## ✦ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✦ Observação

Este é um projeto-conceito desenvolvido para demonstração de portfólio.

A personagem Luna Martins, os projetos, números e depoimentos apresentados no site são fictícios e possuem finalidade exclusivamente demonstrativa.

## ✦ Publicação

O projeto foi desenvolvido para funcionar como um site estático e pode ser hospedado através do GitHub Pages.
